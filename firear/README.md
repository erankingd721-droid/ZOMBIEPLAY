# האתר של Fire AR

אתר אישי לערוץ: לייבים, סרטונים, הקהילה והקישורים. הכול מתעדכן לבד.

## מה מתעדכן לבד

| מה | מאיפה |
|---|---|
| **לייב עכשיו** (פס אדום למעלה, מסך בכותרת, כרטיס "מצב השידור") | Kick, בדיקה כל דקה |
| **עוקבים ב-Kick** + יעד העוקבים הבא | Kick |
| **"מה משחקים לאחרונה"** | הקטגוריות האחרונות ב-Kick |
| **סרטונים, שורטס ולייבים חדשים ביוטיוב** | ה-RSS של יוטיוב (10 האחרונים) |
| **לייבים מ-Kick וקליפים** | Kick |

מספר המנויים ביוטיוב שמור בקובץ `data/youtube.js`. כדי שיתעדכן לבד, מוסיפים מפתח API (בהמשך).

## לשנות טקסטים, קישורים וצבעים

הכול בקובץ **`config.js`**, עם הסבר ליד כל שורה.
דיסקורד: רק קישור הזמנה שלא פג (בדיסקורד: הזמנה ← תוקף "אף פעם").

## להעלות לאינטרנט (בחינם) ולקבל קישור לשלוח

1. נכנסים ל-https://app.netlify.com/drop (כניסה עם Google).
2. גוררים את **כל התיקייה** של האתר לחלון.
3. מקבלים כתובת כמו `name.netlify.app` (אפשר לשנות בהגדרות), ואותה שולחים לחברים.

אחרי שינוי: גוררים שוב את התיקייה (Deploys ← גרירה).

## אופציונלי: מנויים בזמן אמת + זיהוי לייב ביוטיוב

1. https://console.cloud.google.com ← פרויקט חדש ← להפעיל **YouTube Data API v3** ← Credentials ← **API key**.
2. ב-Restrict key: Websites ← כתובת האתר (למשל `https://name.netlify.app/*`), וב-API restrictions רק YouTube Data API v3.
3. מדביקים ב-`config.js` בשורה `youtube.apiKey`.

## לבדוק במחשב

בתיקייה של האתר: `npx serve .` ופותחים את הכתובת שמופיעה.

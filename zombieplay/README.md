# 🧟 האתר של ZombiePlay

אתר אישי לערוץ, בסגנון של shotist.net, אבל שלך: ירוק-שחור, הזומבי שלך, והנתונים מהיוטיוב ומה-Kick שלך.

## מה מתעדכן לבד

| מה | מאיפה |
|---|---|
| **לייב עכשיו** (פס אדום למעלה, מסך בכותרת, כרטיס "מצב השידור") | Kick, בדיקה כל דקה |
| **עוקבים ב-Kick** + יעד העוקבים הבא | Kick |
| **"מה משחקים לאחרונה"** | הקטגוריות האחרונות ב-Kick |
| **סרטונים, שורטס ולייבים חדשים ביוטיוב** | ה-RSS של יוטיוב (10 האחרונים) |
| **הלייב האחרון** | יוטיוב, או Kick אם היה שם לייב חדש יותר |
| **קליפים מ-Kick** | לשונית "קליפים" מופיעה לבד ברגע שמישהו עושה קליפ |

מספר המנויים ביוטיוב שמור בקובץ `data/youtube.js` (104 נכון להיום). כדי שיתעדכן לבד, מוסיפים מפתח API (סעיף בהמשך).

## לשנות טקסטים, קישורים וצבעים

הכול בקובץ **`config.js`**, עם הסבר ליד כל שורה. הדברים הכי חשובים:

- **דיסקורד:** כל קישורי ההזמנה בתיאורים של הסרטונים פגו. בדיסקורד: לוחצים על שם השרת ← "הזמנת אנשים" ← "עריכת קישור ההזמנה" ← תוקף: **אף פעם לא**. מדביקים ב-`links.discord`.
- **טיקטוק / אינסטגרם:** מדביקים את הקישור (או רק את ה-@) ב-`links.tiktok` / `links.instagram`.
- **הכותרת הראשית:** `hero.line1` / `hero.line2` (עכשיו: "מת מצחוק. / חי בלייבים.").
- **לוח שידורים:** ממלאים את `schedule` והכרטיס מופיע לבד.
- **הצבע:** `accent`.

## להעלות את האתר לאינטרנט (בחינם)

האתר הוא קבצים סטטיים, אז אפשר להעלות אותו לכל שירות אחסון חינמי.

**הכי פשוט: Netlify Drop**
1. נכנסים ל-https://app.netlify.com/drop (אפשר להירשם עם Google).
2. גוררים את **כל התיקייה** של האתר לחלון.
3. תוך כמה שניות מקבלים כתובת כמו `zombieplay.netlify.app` (אפשר לשנות את השם בהגדרות).

כדי לעדכן אחרי שינוי ב-`config.js`: גוררים שוב את התיקייה (Deploys ← גרירה).

**דומיין משלך** (כמו `zombieplay.co.il`): קונים דומיין, ובהגדרות של Netlify ב-Domain management מוסיפים אותו לפי ההוראות.

## אופציונלי: מספר מנויים בזמן אמת + זיהוי לייב ביוטיוב

1. נכנסים ל-https://console.cloud.google.com, יוצרים פרויקט.
2. מפעילים את **YouTube Data API v3**, ואז Credentials ← Create credentials ← **API key**.
3. **חשוב:** ב-Restrict key בוחרים Websites ומוסיפים את הכתובת של האתר (למשל `https://zombieplay.netlify.app/*`), וב-API restrictions רק YouTube Data API v3. ככה אף אחד אחר לא יכול להשתמש במפתח.
4. מדביקים ב-`config.js` בשורה `youtube.apiKey`.

## לבדוק במחשב לפני שמעלים

צריך שרת קטן (בגלל הנתונים מ-Kick). בתיקייה של האתר, בטרמינל:

```
npx serve .
```

ופותחים את הכתובת שמופיעה.
